## 伤害计算

角色规则位于 `resources/meta-sr/character/星神★阿哈/calc.js`，装备规则分别位于 `weapon/欢愉/calc.js` 和 `artifact/calc.js`。

- 阿哈：普攻、战技自身追加攻击、对单全弹射终结技、欢愉技直伤、欢愉技真实伤害、秘技额外回合和有目标生命记录时的欢愉负债。行迹速度门槛为 125/150，对应欢愉度提高 120%/150%；未解锁行迹不生效。
- 一魂：欢愉伤害增笑 15%。二魂：欢愉万相的暴击率/无视防御由 12%/30%替换为 20%/60%。三、五魂：通过角色技能等级数据增加倍率。四魂：真实伤害比例从 20%提高到 25%，另计队友好活当赏。六魂：负债占用生命上限至少 20%；100 笑点获取和行动提前属于回合事件，不自动重复叠加到每次攻击。
- 「在世界尽头相会吧！」：每名欢愉角色提供 6%–10%暴击伤害；阿哈在场额外提供 12%–20%。人数默认仅装备者 1 名，可配置 1–4。
- 「当第一声「阿哈」响起」：叠影 1–5 增加基础速度 12/14/16/18/20，参与速度百分比乘算；对其他我方单体施放战技后，无视防御 16%/18%/20%/22%/24%。获取的笑点包含在本次攻击的笑点参数中，不额外重复计入。
- 「神的瞬息欢愉」：常驻速度提高 6%；达到 40%欢愉度时的进场行动提前只作条件说明，不乘到单次伤害上。
- 「亚空异容所」：常驻速度提高 6%；速度达到 145 后全队击破特攻提高 18%，提供避免重复叠加的开关。

默认场景为 100 笑点/好活当赏、欢愉万相与天赋爆伤生效、单个敌人；秘技场景为 20 笑点且上述两项状态关闭。模型计算单次攻击，不模拟行动轴、愿力恢复、笑点返还或完整队伍轮转。战技令使的额外 20%欢愉伤害使用队友属性，缺少该队友数据时不计入阿哈自身战技结果。

可在自定义计算规则中设置以下参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `punchline` | 100 | 本次攻击计入的笑点或好活当赏，已包含武器等来源 |
| `ahaGlorious` / `ahaTalentBuff` | `true` / `true` | 欢愉万相、天赋暴击伤害是否生效 |
| `elationCount` / `ahaInTeam` | 1 / `true` | 欢愉队员人数、阿哈是否在场 |
| `teammateBanger` | 0 | 四魂额外计入的队友好活当赏总和 |
| `ahaLightconeSkillTriggered` | 未指定时视为已触发 | 设为 `false` 关闭五星光锥的战技后无视防御 |
| `enemyCount` | 1 | 欢愉技命中的敌人数，1–5；按同等防御与抗性计算 |
| `ahaMomentDamage` | 0 | 本次阿哈时刻其他目标已造成的非真实伤害总和，不含阿哈本次欢愉技 |
| `ahaMomentAvgDamage` | `null` | 上一项的期望伤害；未指定时使用 `ahaMomentDamage` |
| `entryJoy` / `entrySpeed` | 使用当前计算快照 | 遗器门槛所需的进场欢愉度/速度；与当前值不同时显式提供 |
| `subspaceBuffAlreadyApplied` | `false` | 已有同套 18%击破特攻时设为 `true`，避免再次计入 |
| `enemyMaxHp` / `enemyHpAfterHit` | 不提供 | 同一目标未被占用前的生命上限、本次伤害后的当前生命；提供后显示负债结算 |
| `enemyHitHpLoss` / `ahaPreviousDebt` | 0 / 0 | 本次对目标造成的实际生命损失、此前负债占用量 |

欢愉技真实伤害先以所有目标的非真实伤害合计乘以 20%（四魂 25%），再按敌人数均分；不会再次经过暴击、防御、抗性或增笑乘区。负债占用量按普通上限 10%与六魂下限 20%处理，只有占用部分与当前生命重叠时才计算生命流失，不把占用上限直接当成额外伤害。
